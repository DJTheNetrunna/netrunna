Archive ingestion

Every external resource listed in the bundled Awesome Piracy Markdown is converted into a searchable NETRUNNA node at runtime, with its original section and subsection kept as tags.

Local-first controls

Saved resources, compact view preference, and visit history are kept in browser storage. No account is required.

Offline shell

The service worker caches the main pages, core data, scripts, styling, and the Awesome Piracy source archive so the catalog remains available after a successful load.
